稀疏检索（Sparse Retrieval）—— 传统关键词思路 BM25 / TF-IDF
向量形态
几万维，绝大多数是 0
高维，少数非零
本质：数词频——"快递"这个词在文档里出现了几次

稠密检索（Dense Retrieval）—— 语义向量思路路 Embedding 模型
向量形态
几百~两千维，全是数值
本质：理解语义——把文本映射到一个"语义空间"，意思相近的文本，向量距离就近

加权排序器
cos
内积
量纲不一样的话
加权时需要注意

tf-idf

idf衡量一个词的稀有程度
一个词，包含该词项的文档数很少

tf为词频

如果一个文章的词频很多，但它的逆文档频率又很低，则，这篇文章可以很好地代表这个词

bm25
信息检索领域的排名算法，用于计算查询与文档之间的相关性得分。
改进了tf-idf算法。
长度归一化（短文档、长文档）D 长度惩罚（文档过长，数整体变小）
词频饱和机制（不随词频增加而线性增加）
